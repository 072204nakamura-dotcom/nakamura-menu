献立管理システム　使い方

毎日の献立を記録して、印刷・お品書きまで作れます

1. まず開いたら

画面の上から順に、次のものが並んでいます。

  • 右上：☁️ クラウド設定（保存先の登録。最初に1回だけ）
  • 4つのタブ：✏️ 入力 📷 AI読み取り 📚 履歴 📊 集計
  • その下：❓ 使い方（このページ）と 💬 ご意見箱
📱 iPhoneはSafariで開いて、共有ボタン →「ホーム画面に追加」をすると、アプリのように使えます。ほかのブラウザだと印刷やクラウドがうまく動かないことがあります。

2. 献立を見る（履歴）

  1. 📚 履歴タブを開きます。
  2. 保存した献立が新しい順に並んでいます。
  3. 並び替えや絞り込みは、上のボタンを押します。
    🕐 新しい順 📅 古い順 ☀ ランチのみ 🌙 ディナーのみ 🍱 オードブルのみ
  4. 中身を見たいときは、その献立の 詳細 を押します。

3. 献立を登録する（入力タブ）

  1. ✏️ 入力タブを開きます。
  2. いちばん上で種類を選びます。
    ☀ ランチ 🌙 ディナー 🍱 オードブル
    （オードブルはテイクアウト用。皿は13枚まであり、使う分だけ入力すればOKです）
  3. 日付とお客様名を入れます（お客様名は空欄でもOK）。
  4. 各皿に入力します。
料理名入力すると緑の見出しにも表示されます
食材使う食材。「、」区切りで並べます
調理法ロースト、マリネ など
ソース合わせるソース
トッピング仕上げにのせるもの
📷 画像📷 選択 / 撮影 で写真を1枚つけられます。小さい写真をタップすると削除できます
  1. 皿は ⠿ を長押し・ドラッグで順番を入れ替えられます。
  2. 最後に 💾 この献立を保存する を押します。「✅ 保存しました」と出たら完了です。

4. 🎤 音声でまとめて入力する

1皿ずつ打たなくても、話すだけで全皿に入れられます。

  1. 皿の上にある 🎤 まとめて音声入力 を押して開きます。
  2. 入力欄をタップして、キーボードのマイク🎤を押します。
  3. 「次」で皿を区切り、「食材は」の後に食材を話します。
    例：「パテドカンパーニュ 食材は豚肉と鶏レバー 次 鯛のマリネ 食材は鯛と大根 次 …」
  4. 話し終えたら ⬇️ 各皿に振り分ける（話し終えたら必ず押す） を押します。「⬇️ ◯皿に振り分けました」と出ます。
  5. 各皿に入った内容を確認して、直したいところは手で直します。
💡 振り分けを押し忘れて保存しても、料理名が全部空のときは自動で振り分けてから保存されます。編集画面にも同じ音声入力があります。

5. 直す・消す・使い回す

✏️ 編集保存した献立を開いて直します。直したら 💾 上書き保存する を押します
＋ 皿を追加するオードブルの編集画面だけに出ます。皿が足りないとき押すと空の皿が増えます
📋 コピー同じ献立を別の日付・別のお客様用に複製します。元の献立はそのまま残ります
削除その献立を消します。確認が出ます。消すと戻せません

6. 印刷・お品書き・画像

履歴の各献立にあるボタンで作れます。

🖨 印刷献立メモ（厨房用のA4・1枚）。左の料理名欄は白いので手書きもできます
📜 お品書きお客様用のお品書き。A4に同じものが上下2枚入り、切って2席分に使えます
🖼 画像お品書きを写真（PNG）として保存します。LINEやInstagramで送るときに便利です
📱 iPhoneで印刷するとき：ボタンを押すと少し待ってから印刷画面が開きます。プリンタを選んで印刷、または「PDFとして保存」もできます。

7. クラウド（iPhoneとPCで同じデータを見る）

保存した献立は自動でクラウドにも送られます。別の端末で見るときは📊 集計タブの下の方にあるボタンを使います。

💾 クラウドに保存する（この端末 → クラウド）この端末のデータをクラウドへ送ります
📥 クラウドから読み込む（クラウド → この端末）クラウドのデータをこの端末に取り込みます。「クラウド側：◯件／この端末側：◯件」と確認が出るので、件数を見てからOKを押してください。この端末のデータは置き換わります
⚙️ URLを設定 / 変更するクラウドの住所（URL）の登録。新しい端末で最初に1回だけ行います
⚠️ アプリを開いただけではクラウドは読み込まれません（うっかり上書きを防ぐためです）。別の端末の最新データが見たいときは 📥 クラウドから読み込む を押してください。

8. 言葉の意味

ランチ前菜3点盛り＋皿6枚のコース
ディナー皿9枚＋肉料理セレクト（4種から選ぶ）のコース
オードブルテイクアウトの盛り合わせ。皿は最大13枚＋追加もできます
献立メモ厨房で使う一覧表。🖨 印刷 で出るもの
お品書きお客様のテーブルに置く和風のメニュー表
クラウドインターネット上の保存場所。iPhoneとPCの橋渡し役

9. 困ったとき

「日付を入力してください」と出る日付が空です。入力タブの一番上で日付を選んでから保存してください
「⚠️ 内容を書いてください」と出るご意見箱の内容が空です。ひとこと書いてから送信してください
「クラウドURLが未設定です」と出る右上の ☁️ クラウド設定 からURLを登録してください（店主に聞けばURLが分かります）
別の端末のデータが見えない集計タブの 📥 クラウドから読み込む を押してください
音声で話したのに皿に入らない⬇️ 各皿に振り分ける（話し終えたら必ず押す） を押したか確認してください
印刷が切れる・白紙になるiPhoneはSafariで開いているか確認してください。一度タブを閉じて開き直すと直ることがあります
画面が古いままページを再読み込みしてください（PCは Ctrl＋Shift＋R）

ここに載っていないこと、分かりにくいところは、アプリ上部の 💬 ご意見箱 から送ってください。小さなことでも大歓迎です。
